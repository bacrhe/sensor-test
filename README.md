## 📚 ТУТОРІАЛ — 10 етапів

### Етап 1: 📹 Калібрування камери
- Настройка гіроскопа та позиціонування
- Дозволяє гравцю знайти зручну позицію для гри

### Етап 2: 👣 Механіка руху
- Вчить свайпи на сітці 13×13
- Свайп вверх/вниз/вліво/вправо = крок у відповідному напрямку

### Етап 3: ⚔️ Блокування тиском
- Поворот телефону до альбомної орієнтації (|γ|>45°) активує **Режим маяка** 🔺
- В цьому режимі замість атаки — накопичення **ТИСКУ** (заряду)
- Заряд захищає від ударів

### Етап 4: 🧱 Знищення об'єктів
- 2 статичні неживі перешкоди (кристали)
- Гравець вчиться атакувати що-небудь неживе

### Етапи 5–9: ⚡ Прогресивні батали
- **1 на 1** (1 фантом)
- **1 на 2** (2 фантоми)
- **1 на 8** (8 фантомів) ← найскладніший
- **1 на 3** (3 фантоми)
- **1 на 4** (4 фантоми)

На кожному етапі гравець може помертти, і йому буде запропонована вибір складності.

### Етап 10: 🎚️ Вибір складності

**Три варіанти:**

- 🟢 **ЛЕГКО** — мало ворогів, повільні атаки
- 🟡 **НОРМАЛЬНО** (рекомендовано) — збалансовано
- 🔴 **ВАЖКО** — багато ворогів, сильні боси

## 🗺️ РЕЖИМ ПРИГОДИ — Чергуючі кімнати

### Карта 13×13

```
Координати: (0,0) до (12,12)
Центр: (6,6)
```

### Тип кімнати (шахматна дошка)

```
Білі кімнати:     (x+y) % 2 === 0
Чорні кімнати:    (x+y) % 2 === 1

Приклад:
  (6,6) = 12 % 2 === 0 → БІЛА
  (6,7) = 13 % 2 === 1 → ЧОРНА
  (7,7) = 14 % 2 === 0 → БІЛА
```

### ⬜ Білі кімнати (Безпечні коридори)

- ✅ **Немає ворогів**
- 🎯 Місця для відпочинку, переходу
- 📦 (Опціонально) Магазини, головоломки, пастки (але безпечні)
- 💚 Стартова позиція: (6,6) — біла

### ⬛ Чорні кімнати (Небезпечні)

- ☠️ **Є вороги**
- 📈 Кількість ворогів масштабується з відстанню від центру (6,6):

  ```
  Дистанція 1–2: базова кількість (залежить від складності)
  Дистанція 3–4: базова × 1.5
  Дистанція 5–6: базова × 2.0
  Дистанція 7+:  базова × 2.5+
  ```

- 👹 **На краях (дистанція ≥ 5)** можуть бути **БОСИ**
  - Стійші, 2–3× більше HP
  - Агресивніші AI

## 🎮 Управління та механіки

### Основне управління
- **Свайп** (вверх/вниз/вліво/вправо) = крок на сітці
- **Жест розмаху рукою** = удар клинком
- **Нахил вниз** (книжна) = Режим атаки (молнія ⚡)
- **Нахил вбік** (альбомна) = Режим захисту (маяк 🔺, накопичення тиску)
- **Клинець зіткнення** = клинч (обопільна блокування)

### Стани характеру

```
ЗЕЛЕНИЙ     = здоров'я 100%, нормальне
ЖОВТИЙ      = здоров'я 50–99%
ОРАНЖЕВИЙ   = здоров'я 25–49%
ЧЕРВОНИЙ    = здоров'я 1–24%, критичний
ПОВНА ЧОРНЬ = мертв (разоружен або 0 HP)
```

## ⚙️ Налаштування складності

Складність впливає на:

- **Темп руху ботів** (легко → повільні, важко → швидкі)
- **Вибір ударів** (легко → прямі, важко → фланкування + підступи)
- **Аггресія** (легко → чекають, важко → атакують відразу)
- **Кількість в кімнатах** (легко → 1–2, норм → 2–4, важко → 3–8+)

## 🔧 Код & архітектура

### Вбудована прогресія (в `<script>`)

Весь код туторіалу + режиму пригоди вбудований у HTML-файл у першому `<script>` теґі:

```html
<script>
  const GameProgress = { ... };
  function initTutorial() { ... }
  function showTutorialStage(stage) { ... }
  // ... інший код ...
</script>
```

### Основні функції

| Функція | Опис |
|---------|------|
| `initTutorial()` | Запустити туторіал з етапу 1 |
| `showTutorialStage(stage)` | Показати модальне вікно етапу |
| `advanceTutorial()` | Перейти до наступного етапу |
| `startTutorialBattle()` | Запустити батал з необхідною кількістю ботів |
| `completeTutorial()` | Закінчити туторіал, перейти до режиму пригоди |
| `enterAdventureMode(x, y)` | Увійти до кімнати (x, y) |
| `updateRoomType()` | Визначити тип кімнати (біла/чорна) |

### Стан гравця

```javascript
window.GameProgress = {
  tutorialStage: 0–10,      // Поточний етап туторіалу
  tutorialComplete: false,   // Чи завершено?
  battleStage: 0–4,         // Поточна фаза батала (1v1, 1v2, 1v8, 1v3, 1v4)
  selectedDifficulty: 0–2,  // 0=easy, 1=normal, 2=hard
  adventureMode: false,      // Чи в режимі пригоди?
  currentRoom: {x, y},      // Поточна позиція
  roomType: 'white'|'black' // Тип кімнати
};
```

## 🐛 Відомі проблеми & рішення

### Проблема: Туторіал не запускається

**Рішення:** Переконайтесь, що JavaScript працює і дозволи затвердже́ні.

### Проблема: Боти не спавняться у чорних кімнатах

**Рішення:** Функція `spawnPhantoms()` повинна вызватися. Перевірте консоль браузера.

### Проблема: Гіроскоп не працює

**Рішення:**
- iOS: використовуйте **Safari**, а не Chrome
- Android: перейдіть на **Chrome** з **HTTPS** (GitHub Pages підтримує)
- Проверяйте лог (`LOG` кнопка вліво внизу)
